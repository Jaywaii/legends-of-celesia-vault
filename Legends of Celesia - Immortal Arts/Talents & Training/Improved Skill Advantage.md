# Improved Skill Advantage

### Prerequisites

Skill Advantage lineage trait.

### Benefits

Select a skill with which you have the skill advantage lineage trait. You gain an additional +1 advantage on that skill's checks.

### Special

You can take this talent multiple times. Each time you take it, either select a skill already affected by this talent and its effects stack, or select a new skill with which you have the skill advantage lineage trait.

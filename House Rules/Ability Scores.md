# Ability Scores

# Ability Score Generation

- **Roll:** Roll 3d6 six times. Any 1s become 2s. Allocate each result as desired.
- **Point-Buy:** All ability scores start at 8. You have 10 points to spend on increasing all six ability scores. Use the following ability score point costs below.

|  |  |  |  |  |
|---|---|---|---|---|
| Ability Score | Point Cost |  | Ability Score | Point Cost |
| 7 | -1 |  | 13 | 6 |
| 8 | 0 |  | 14 | 7 |
| 9 | 1 |  | 15 | 8 |
| 10 | 2 |  | 16 | 9 |
| 11 | 3 |  | 17 | 10 |
| 12 | 5 |  | 18 | 11 |
